# Sundown Studio

A modern, highly interactive landing page showcasing a multi-disciplinary design and production studio. Built with a focus on immersive user experiences, smooth animations, and premium aesthetics.

## 🌟 Features

- **Smooth Scrolling:** Implemented using Locomotive Scroll for a buttery smooth navigation experience.
- **Dynamic Animations:** Custom CSS animations and gooey effects for interactive elements.
- **Image Carousels:** Powered by Swiper.js for elegant presentation of featured content.
- **Interactive UI:** Custom hover effects and content revealing interactions for an engaging experience.
- **Responsive Design:** Optimized for both desktop and mobile viewing.
- **Custom Fonts:** Premium typography setup using Neue Haas Display.

## 🛠️ Technologies Used

- **HTML5** for semantic structure.
- **CSS3** for styling, custom animations, and responsive layouts.
- **Vanilla JavaScript** for DOM manipulation, event handling, and library integrations.
- **[Locomotive Scroll](https://locomotivemtl.github.io/locomotive-scroll/)** for smooth scrolling.
- **[Swiper.js](https://swiperjs.com/)** for touch-enabled sliders.

## 💻 Running Locally

To run this project locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/Sheersh01/Sundown-Studio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Sundown-Studio
   ```
3. Open `index.html` in your browser. (For the best experience, we recommend using a local development server like the "Live Server" extension in VS Code to ensure all assets and scripts load correctly).

## 📁 Project Structure

- `index.html` - The main HTML entry point containing the structure.
- `style.css` - Contains all styles, media queries, and animation keyframes.
- `script.js` - Contains logic for Locomotive Scroll, Swiper initialization, and custom interactions.
- `Assets` - Various `.webp`, `.svg`, `.mp4` files, and custom fonts used for visual content.
